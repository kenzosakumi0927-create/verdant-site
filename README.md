## このサイトについて

外壁塗装業界向けに制作したホームページのデモテンプレートです。  
営業・提案資料として、実際のクライアントへ展開する際のベース構成として活用できます。

**設定**
- 架空企業: VERDANT（ヴァーダント）外壁塗装
- 架空所在地: 架空県 駿河市 青葉台
- 業態: 戸建て・倉庫・アパートの外壁／屋根塗装

## ローカルでの確認方法

### 方法1：そのままブラウザで開く
`index.html` をダブルクリック。

### 方法2：ローカルサーバーで起動（推奨）
```bash
cd ~/Downloads/verdant-site
python3 -m http.server 8080
```
→ ブラウザで `http://localhost:8080/`

## 機能一覧

### ✓ 配色テーマ切り替え（画面右側）
- Forest（緑×銅）／ Navy（紺×金）／ Sumi（墨×朱）／ Indigo（和紙×藍）

### ✓ Before/Afterスライダー
中央のラインを左右にドラッグして塗装前後を比較。

### ✓ 見積もりシミュレーター
階数・坪数・施工内容・塗料グレードを選ぶと金額がリアルタイム計算。

### ✓ AIチャット相談（右下のボタン）
デモ用の定型回答。本番ではCloudflare Workers + Claude APIに接続。
